# ИИ-консультант Store — фронтенд

Задача хакатона ИИкузница, трек «Клиентские сценарии»: агент, который помогает клиенту
выбрать ПО на сайте Store, отвечает на вопросы о продуктах и готовит КП.

React 18 + TypeScript + Vite. Палитра «Бордо» из макетов Figma.

## Запуск

Через Docker из папки `support-assistant` — бэкенд и фронтенд в одном контейнере:

```bash
docker compose up --build
```

| Адрес | Что это |
| --- | --- |
| http://localhost:8080/ | Демо-витрина Store с виджетом консультанта (кнопка справа внизу) |
| http://localhost:8080/chat | Тот же чат на весь экран (мобильные, iframe) |
| http://localhost:8080/operator | Кабинет менеджера: обращения |
| http://localhost:8080/operator/quotes | Очередь КП на проверку |
| http://localhost:8080/operator/analytics | Метрики |

Клиент и менеджер синхронизируются через сервер (WebSocket) — можно открыть с разных устройств.
Режим разработки, деплой на Railway и переменные окружения — в [../README.md](../README.md).

## Демо-сценарий для питча

1. На витрине «Подобрать с ИИ» → «не знаю, что нужно, но хотим защитить почту и файлы на 50 сотрудников».
2. Агент вытаскивает из фразы задачу и количество, задаёт 3 уточняющих вопроса (почта, срок, бюджет).
   Сверху видно «Учитываю 5/5».
3. Два варианта по ценам из каталога Store (Kaspersky для почтовых серверов + KES Стандартный + Кибер Бэкап
   против Dr.Web), с обоснованием, бюджетом и таблицей сравнения, со ссылками на карточки Store.
4. «Есть российский аналог?» → агент показывает российские замены из каталога → «Заменить на аналог».
5. «Сформировать КП» → форма компании в чате → черновик КП по шаблону Softline («Открыть»).
6. В кабинете менеджера: требования клиента, ИИ-резюме, КП → «Согласовать и отправить» — у клиента статус меняется.

Второй сценарий (реальная реплика из переписок): «85 лицензий Kaspersky Endpoint Security для бизнеса Стандартный —
какие есть и в чём разница?» → сверка редакций Стандартный / Расширенный / Расширенный Плюс по цене за 85 узлов.

## Что умеет

**Клиент:** два сценария (знает продукт / подбор), уточняющие вопросы кнопками, карточки ПО (вендор, редакция,
тип лицензии, платформы, реестр ПО, цена), варианты с обоснованием, сравнение, российские аналоги,
ответы по базе знаний с источниками, 👍/👎 к ответам, форма данных для КП, превью и печать КП в PDF,
передача менеджеру (по кнопке, при запросе скидки/закупки, при негативе, если ИИ дважды не понял).

**Менеджер:** очередь обращений, подключение к чату и подсказки ИИ, требования клиента и предложенные варианты,
ИИ-резюме, очередь КП с редактированием позиций и условий, согласование и отправка, аналитика.

## Данные

Агент работает на **настоящих данных Store** (сам агент — на сервере, `../backend/internal/agent`):

| Что | Откуда | Как обновить |
| --- | --- | --- |
| Каталог: 6 000 продуктов, 33 903 позиции с ценами | товарный фид `Mindbox.yml.gz.xml` | `python3 data/build_catalog.py Mindbox.yml.gz.xml backend/data/catalog.json.gz` |
| Категории обращений и реальные формулировки | `чаты поддержки/*.txt` (495 обращений) | `python3 data/build_chats.py "чаты поддержки" backend/data/chats.json` |
| База знаний | store.softline.ru/delivery_info, docs.softline.com | `backend/internal/agent/kb.go` |
| Шаблон КП | «Шаблон КП ПАО Софтлайн» | `src/components/QuoteDocument.tsx`, `src/config.ts` |

Команды запускаются из папки `support-assistant`. Сам фид (290 МБ) в репозиторий не кладём — в `.gitignore`.

Как агент считает цену по фиду (`PriceFor` в `backend/internal/agent/catalog.go`):
- **цена за единицу в диапазоне** — Kaspersky «цена при 50–99 узлах» × количество;
- **пакет** — MDaemon «до 30 пользователей», Dr.Web «на 50 ПК»: берётся наименьший подходящий пакет;
- **за штуку** — серверные и бессрочные лицензии.

Срок подбирается точный, иначе ближайший (с пометкой). Новая лицензия, продление и миграция — разные позиции.

Честность данных:
- «В реестре ПО, № …» показываем, только если номер есть в фиде (у 82 продуктов). Иначе — «Российский разработчик» по списку вендоров в `data/build_catalog.py`.
- В КП НДС «Без НДС» — только при номере реестра из фида; у остальных позиций «уточняется», ставку выбирает менеджер.
- Если продукта нет в онлайн-каталоге (Power BI, ArchiCAD), агент так и говорит и передаёт менеджеру.

Демо-обращения в кабинете — реальные реплики из переписок (номера тоже оттуда), прогнанные через того же агента.

## Связь с сервером

UI работает только через интерфейс `SupportApi` (`src/api/client.ts`); сервер — на Go в `../backend`.

| Файл | Что делает |
| --- | --- |
| `src/api/types.ts` | формат данных (Ticket, Message, Product, Quote, события) — совпадает с `backend/internal/model/types.go` |
| `src/api/client.ts` | интерфейс API; эндпоинты описаны в комментариях |
| `src/api/http.ts` | клиент сервера: REST + WebSocket `/api/ws` |

В режиме разработки (`npm run dev`) запросы `/api` проксируются на сервер (`API_PROXY`, по умолчанию http://localhost:8000).

Сообщение агента может нести `offers`, `products`, `compare`, `sources`, `quickReplies`,
`form: 'quote_request'` и `quoteId`; обращение хранит `requirements`, `pendingSlot`, `lastOffers`, `quoteId`.
